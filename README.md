# ALVO Company Portal — GitHub Pages

Arquivos prontos para publicação estática.

## Publicação
1. Crie um repositório público no GitHub, por exemplo `alvo-company-portal`.
2. Envie `index.html` e `.nojekyll` para a raiz do repositório.
3. Vá em Settings → Pages.
4. Em Build and deployment, escolha "Deploy from a branch".
5. Selecione `main` e `/ (root)`.
6. Salve.
7. O GitHub mostrará a URL pública do portal.

O portal usa Supabase somente como backend:
- Auth
- Banco
- Edge Functions
- Mercado Livre OAuth
- Sincronização
- Webhooks

Nenhuma chave secreta é incluída neste site.
